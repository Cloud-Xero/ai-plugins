# X（旧Twitter）運用テクニック・投稿ノウハウ調査レポート（2025〜2026年）

調査日: 2026-07-12 / 調査範囲: 日本語圏・英語圏のWeb情報（出典は末尾に一覧）

---

## 1. 概要

2025〜2026年のXは「アルゴリズムの世代交代期」にある。2025年10月にイーロン・マスクが「Grokがレガシーの推薦システムを置き換える」と発表し、2026年1月にはRustベースの新アルゴリズム（github.com/xai-org/x-algorithm）が公開された。従来の「手作りルールの加点方式」（ハッシュタグ加点・フォロワー数ボーナス等）は廃止され、**Grok由来のAIが投稿内容そのものを意味的に読み、ユーザーごとに19種類の行動確率を予測してスコアリングする方式**に転換している。

運用面での本質的な変化は次の3点に集約される。

1. **量より質・滞在時間**: 「投稿の数」より「1投稿あたりの滞在時間・保存・リポスト」が評価される。連投は指数関数的に減衰される。
2. **会話（リプライ）が最強のシグナル**: リプライ、特に「投稿者が返信を返した会話」への重みが突出して大きい。
3. **ネガティブシグナルの重み**: 「興味なし」・ミュート・ブロック・通報にはマイナスの重みがかかる。「バズるが嫌われる投稿」より「控えめだが好かれる投稿」が有利。

日本語圏のノウハウも英語圏のノウハウも、結論はほぼ同じ方向に収束している：**フック（1行目）で止め、本文で滞在させ、末尾で会話・保存・プロフィールクリックを促す**。

## 2. アルゴリズム（2025〜2026年の仕様・変更点）

### 2.1 スコアリングの仕組み（2026年公開版）

- 投稿スコアは **AIが予測する19個のアクション確率の加重合計**。ポジティブ15種（いいね・返信・リポスト・引用・クリック・プロフィール閲覧・動画再生・画像拡大・シェア3種・滞在時間・フォロー等）＋ネガティブ4種（「興味なし」・ブロック・ミュート・通報）。ネガティブには**負の重み**。（[note: tatsuki][s12]）
- フィード生成は7ステップ: 行動履歴読込 → 候補収集（フォロー内: Thunder / フォロー外: Phoenix Retrieval）→ メタデータ付与 → 一次フィルタ → AI採点（確率予測→加重合算→連投減衰→Out-of-Network調整）→ スコア順配列 → 最終フィルタ。（[s12]）
- **AuthorDiversityScorer** により同一著者の投稿は指数関数的に減衰。最高スコアの1本のみほぼ無減点で、2本目以降は急減。スレッドも同一会話ツリーから最高スコア1本のみが配信される。（[s12]）
- 学習済み重み・具体的パラメータ値は非公開のため、以下の倍率は各社の分析・実測に基づく推定値である点に留意。

### 2.2 エンゲージメントの重み（いいね=1x とした推定値）

| アクション | 重み（推定） |
|---|---|
| いいね | 1x |
| ブックマーク | 10x |
| プロフィールクリック | 12x |
| リポスト | 20x |
| 引用ポスト | 25x |
| リプライ | 27x（分析により13.5〜54xの幅） |
| **リプライに投稿者が返信** | **75〜150x（最強シグナル）** |
| 2分以上の滞在 | いいねの約22倍相当 |

（[OpenTweet][s1] / [PostEverywhere][s3] / [active-note][s15]。数値はソースにより幅がある）

### 2.3 滞在時間（dwell time）

- 表示直後の**初動の滞在時間が巨大なシグナル**。「もっと見る（さらに表示）」の展開、画像拡大、動画視聴時間もすべて滞在系シグナル。（[s1][s3][s11]）
- 日本語圏でも「滞在時間・プロフクリック・リプライ・ブックマーク」が4大シグナルとして整理されている。（[アドネスラボ][s11] / [tinsalo][s16]）

### 2.4 外部リンクの扱い（時系列で変化）

- **2025年10月**: 外部リンクペナルティの撤廃がアナウンスされた。
- **2026年初頭**: 実測ベースでは再び締め付けが確認され、本文にリンクを含む投稿は同等の投稿より**初動リーチが約30〜50%減**。非Premiumアカウントのリンク付き投稿は「中央値でほぼゼロエンゲージメント」という分析もある。（[s1][s2][s5]）
- **実務上の結論**: 「本文に価値を直接書き、リンクはリプライ欄（1件目の自リプ）に置く」が2026年時点の定石。日本語圏でも「X内完結」が最適戦略とされる。（[s1][s14]）

### 2.5 初動（投稿直後）の重要性

- **投稿後15〜30分のエンゲージメント速度**が長期リーチの最大の予測因子。15分で10リプライ付く投稿は、24時間かけて同数を集める投稿を大きく上回る。（[s1][s5][s13]）
- 時間減衰は急峻で、**約6時間ごとに可視性が半減**。（[s1]）

### 2.6 旧来テクニックの検証結果（公開コードで否定されたもの）

公開コードの解析により、以下は**根拠なし**と判明している。（[s12]）

- ハッシュタグによる加点ロジック → 存在しない（むしろ2個超はスパム的と扱われ逆効果）
- フォロワー数の直接加点 → 存在しない
- センシティブワードの自動除外リスト → 存在しない
- 投稿時間帯そのものへの重み付け → 存在しない（時間帯が効くのは「初動を稼げるから」という間接効果）

## 3. 投稿パターンの型（構造・例・用途）

英語圏の「50 viral formats」（[OpenTweet][s2]）と日本語圏の型分析（[free-ai-tools][s13] / [アドネスラボ][s11] ほか）を統合し、再現可能な型として整理する。

### 3.0 まず大分類（日本語圏の基本3類型）

| 類型 | 特徴 | 強いシグナル |
|---|---|---|
| **有益型** | 「○○する方法」等、役立つ情報を凝縮 | 保存・リポスト率が高くフォロワー外に届く |
| **共感型** | 失敗談・あるある | いいね・リプライ率が高く関係構築向き |
| **意見表明型** | 「○○は△△だと思う」と立場を明示 | 賛否でインプレッション増（炎上リスクあり） |

（[s13]）

### 3.1 フック（1行目）の型

1行目がスレッド/投稿の成否の8〜9割を決める。伸びやすい1行目の型:

- **数字型**: 「フォロワー100人から3ヶ月で1万人にした方法」— 具体数字で信頼と好奇心を作る
- **悩み代弁型**: 「投稿しても伸びない人、これやってませんか」— ターゲットの内心を言語化
- **逆説・意外性型**: 「毎日投稿はむしろ逆効果です」— 常識への反転でスクロールを止める
- **問いかけ型**: 「もし明日フォロワーが0になったら、何から始めますか？」
- **実績提示型（英語圏定番の公式）**: 「I \[具体的数字の成果\] in \[期間\]. Here's the \[N\]-step system:」

（[s2][s7][s13]）

### 3.2 個別の型カタログ

#### A. 権威性・実績提示型
- **構造**: 実績（数字）→ そこから得た知見の予告 →本文で展開。「\[N年/N件\]やってきて分かった○○」「Everything I know about \[topic\] after \[X years\]:」
- **例**: 「受託開発を10年・100案件やって分かった、見積もりで絶対に外せない3つの前提」
- **用途**: 専門家ポジションの確立、フォロー獲得、プロフィールクリック誘発。プロフィール・固定ポストに実績を置いておくと相乗効果。

#### B. ビフォーアフター型（変化提示型）
- **構造**: Before（過去の状態）→ After（現在の結果）→ 変化の要因。「\[期間\]前は\[状況\]。今は\[結果\]。変わったのはこれ:」
- **例**: 「1年前: 月収20万の会社員。今: 独立して月商150万。変えたのはスキルじゃなくて『売る相手』でした」
- **用途**: 変身・成長ストーリーで希望を売る。実績訴求と保存の両取り。派生形: 「Day 1 vs Day 365」「期待 vs 現実」「私のワークフロー、昔 vs 今」。

#### C. リスト型（有益まとめ型）
- **構造**: 「○○な\[N\]選」「\[N\] things I wish I knew before \[経験\]」＋箇条書き本文。
- **例**: 「フリーランス1年目の自分に教えたい、お金の失敗5つ」
- **用途**: ブックマーク（10x）狙いの主力。チェックリスト・比較表・手順まとめは保存率が最も高い形式。

#### D. 問いかけ・参加型
- **構造**: 低ハードルの質問＋「私から言うと:」と自分が先に答える。「あなたの\[分野\]を3語で。私から:」「\[X\] vs \[Y\]、どっち派？」
- **例**: 「人生を変えた本を1冊だけ挙げるなら？私は『○○』」
- **用途**: リプライ（27x）量産。返ってきたリプに投稿者が返信すると最強シグナル（75〜150x）が積み上がる。リプ欄が推薦リソース集になり保存も付く。

#### E. 逆張り・持論型（contrarian）
- **構造**: 「多くの人は\[X\]と思っている。違う。理由はこれ:」「\[定番アドバイス\]はやめて、\[代替案\]をやれ（Stop/Start型）」
- **例**: 「『まず1000フォロワー』は嘘。100人でも売上は作れます。必要なのは○○」
- **用途**: 賛否両方のリプライ・引用を誘発しインプレッションを最大化。体験ベースの根拠をセットにしないと炎上・ブロック（負のシグナル）に転ぶ。

#### F. ストーリー型（失敗談・共感型）
- **構造**: 「\[やったこと\]。結果どうなったか:」「今年学んだ一番痛い教訓:」「危うく\[最悪の結果\]になりかけた。○○していなければ」
- **例**: 「納品前日にクライアントの要件が全部ひっくり返った話。ここから契約書に必ず入れるようになった一文がある」
- **用途**: いいね・リプライ・ファン化。共感＋学びをセットにするのが基本。

#### G. データ・検証型
- **構造**: 「\[N個\]の\[対象\]を分析した。分かったこと:」「\[意外な統計\]。これが\[読者\]に意味するのは:」
- **例**: 「バズった投稿100本の1行目だけを集めて分類した。9割がこの3パターンだった」
- **用途**: 独自リサーチで権威性と保存を稼ぐ。「実際の数字」は誇張の多いTLで信頼シグナルになる。

#### H. named framework 型（命名型）
- **構造**: 「○○の法則」「The \[X\] framework」と自分のメソッドに名前を付けて解説。
- **例**: 「提案が通る『3つのnot』理論。読まない・信じない・行動しない、を順に壊す」
- **用途**: 記憶に残り引用されやすい。権威性の資産化。

#### I. 圧縮型（1ポスト完結ガイド）
- **構造**: 「○○の完全ガイドをこの1ポストに:」＋長文ポストで箇条書き濃縮。
- **用途**: 長文ポスト（滞在時間◎）とブックマークの両取り。Premiumの長文機能と相性が良い。

#### J. スレッド型（連続ツイート）
- **構造**: フックツイート → 1ツイート1ポイントで4〜8本 → 3〜4本ごとに画像等の視覚的ブレイク → 締めにCTA。
- **用途**: 深掘り解説・新規リーチ。2023年型の20連投メガスレッドは廃れ、**証拠（スクショ・データ）付きの3〜8本の短スレッド**が現在の主流。なお新アルゴリズムでは同一ツリーから最高スコア1本しか配信されないため、1本目（フック）にすべてを賭ける。（[s2][s5][s12]）

#### K. 引用ポスト活用型
- **構造**: 話題の投稿を引用し「共感・対立・笑い・情報性」のどれかを乗せる。自分の過去投稿の引用でリレー型発信も可。
- **例**: 話題のニュースを引用して「受託の現場から見ると、これは○○という意味です」
- **用途**: 引用は重み25xと高く、元投稿の流量に相乗りできる。小規模アカウントの発見経路として有効。（[s16][s19]）

#### L. 保存誘導型（前後比較→手順→保存）
- **構造**: ビフォーアフター提示 → 手順の要約 → 「詳細は固定ポストへ」「保存してあとで見返してください」
- **用途**: ブックマークと固定ポストへの導線を同時に作る。「Save this. You'll need it later:」は英語圏でも定番。

#### M. 共感連帯型
- **構造**: 「これは\[あるある\]で消耗してる人へ。あなただけじゃない」
- **用途**: 感情的シェア・リポスト狙い。コミュニティの結束形成。

### 3.3 本文（140字）の内部構造

短文投稿の基本構造は3パーツ: **フック（1〜2行: 数字・意外性・問いかけ・主張）→ 本文（2〜3行: 根拠・具体例）→ 問いかけ/余韻（1行）**。（[s13]）

長文ポストは **PREP法（結論→理由→具体例→結論）** ＋ 空白行・箇条書きでリズムを作り、冒頭2行で「さらに表示」をクリックさせる。500〜1,000字が目安。（[s11][s14]）

## 4. 運用テクニック

### 4.1 投稿時間帯（日本）

- **ゴールデンタイム: 20〜22時**（帰宅後のリラックスタイム）が最も閲覧・拡散されやすい。
- その他の山: **通勤 7〜9時 / 昼休み 12〜13時**。朝6時と夜21時が最も安定してエンゲージメント率を維持するというデータもある。
- アクティブが増える**少し前**（7時台・12時前）に投稿しておくと初動を拾いやすい。
- 英語圏データでは水〜金の9〜11時（現地時間）がピーク。海外向け発信なら日本の深夜〜早朝。
- ただし新アルゴリズムに時間帯の直接加点はなく、**「フォロワーが起きている時間＝初動が稼げる時間」という間接効果**。自分のアナリティクスでの検証が最優先。（[s12][s20][s21]）

### 4.2 リプライ運用（最重要）

- **投稿後15〜30分はリプライ対応に張り付く**。返信への返信（会話の深さ）が最強シグナル。投稿しっぱなしが最ももったいない。（[s1][s15]）
- **リプ周り**: 自分より2〜10倍規模のアカウントに1日15〜30分、価値のある返信をする。小規模アカウントの最速の成長経路（"reply guy"戦略）。宣伝はしない。（[s5][s9]）
- 投稿前に関連アカウント20件程度に返信して「アルゴリズムを温める」→ 投稿、という順序も有効。（[s15]）
- 量より質: 定型文リプ100件より、会話が続く深い返信5件。（[s11]）

### 4.3 プロフィール導線・固定ポスト

- 導線の設計: **投稿 → プロフィールクリック（12x）→ 固定ポスト → LP/リンク → リード獲得**。この経路を摩擦なくつなぐ。
- bioは「何をしているか」ではなく**「訪問者が何を得られるか」**を書く。検索キーワードを含め、CTA（「無料ガイドはこちら」「相談はDMで」）を置く。
- **固定ポストは軽量セールスページ**として機能させる: 鋭いフック＋明確な約束＋次の1アクション（リードマグネット・LPリンク）。実績まとめや最高傑作スレッドの固定も有効。
- リンク先はトップページではなくリード獲得用LPへ。（[s8][s22]）

### 4.4 フォーマット戦略

- **ネイティブ動画が最優遇**: 1〜2分（短尺なら15〜60秒）、字幕付き・縦型。直接アップロードで最大40%エンゲージメント増、動画は10x級のブースト。
- **画像2〜4枚の図解・比較**も滞在時間を稼げる。
- **長文ポスト（Premium）**は滞在時間で優遇。ファン化・信頼構築向き。新規拡散はスレッド/短文、ファン化は長文、アーカイブはnote等、と使い分ける。（[s11][s14][s16]）

### 4.5 頻度・テーマ設計

- 目安: **本気投稿を1日1〜2本、3〜4時間以上の間隔**（連投減衰対策）。「週3〜5本の質重視」を推す日本語圏ソースもあり、少なくとも「量で押す時代は終了」で一致。英語圏には1日3〜6本＋リプライ多数という流派もあるが、その場合も間隔を空ける。（[s5][s11][s12]）
- **テーマは1〜2つに絞る**: AIが「誰に届けるべきか」を分類しやすくなり、フォロワーの期待とズレず「興味なし」（負のシグナル）を防ぐ。（[s11][s16]）
- コンテンツミックスの目安: 娯楽・人柄40% / 教育30% / 実績・励まし20% / 販促10%。（[s5]）

### 4.6 収益化・ビジネス活用

**インプレッション収益（広告収益分配）**
- 参加条件: X Premium加入（Basic除く）／フォロワー500人以上／2要素認証等。
- **2026年1月改定**: 収益基準が「エンゲージメント数」から**「Premiumユーザーのホームタイムラインでの閲覧」**ベースに変更（過去3ヶ月でPremiumユーザー閲覧500万回が目安）。単純なインプレ稼ぎでは稼げず、**「誰に見られたか」**で決まる。
- 2024年11月以降は返信欄広告ではなく「いいね・リプライ・ブックマーク・閲覧時間」等の反応指標で分配。
- ジャンル単価差が大きい: AI・金融・投資などは広告主のCPMが高く、同インプレでも収益が数倍変わる。（[s23][s24][s25]）

**リード獲得の設計**
- 基本ファネル: 有益投稿（信頼）→ プロフィール → 固定ポスト（リードマグネット）→ LP → メール/DM/商談。
- 外部リンクは本文に貼らず、**固定ポスト・プロフィール・自己リプライ**に集約する。
- 長文ポストをLP代わりに使い「X内で完結して説明→DMやプロフへ」という導線が2026年の定石。（[s8][s14][s22]）

## 5. NG事項（避けるべきこと）

### 5.1 アルゴリズム減点・リーチ低下要因

| NG行動 | 理由 |
|---|---|
| 本文へのURL直貼り（毎回） | 初動リーチ30〜50%減。「外部誘導アカウント」判定でシャドウバン要因にも |
| ハッシュタグの多用 | 加点ロジックは存在せず、2個超はスパムシグナル |
| 短時間の連投（例: 5分で10本） | AuthorDiversityScorerで指数減衰＋スパム判定リスク |
| 「いいねで○○配布」等のエンゲージメントベイト | スパム判定・収益化剥奪リスク |
| 相互フォロー企画・フォロバ乞い | エンゲージメントベイトとして凍結・シャドウバンリスク増 |
| コピー投稿・無断転載・同一文の再投稿 | オリジナリティなし判定・スパム判定 |
| 自分の投稿を毎日セルフリポスト | 「閲覧数稼ぎ」として減点 |
| 攻撃的・断罪的な表現 | ブロック・ミュート・通報＝**負の重み**が直撃 |
| テーマの散漫（何でも屋アカウント） | AIが届け先を分類できず、「興味なし」を誘発 |
| 低品質AI量産文・薄い内容 | 滞在時間ゼロ＋low-effort判定 |

（[s1][s11][s12][s15]）

### 5.2 シャドウバンの主要因（日本語圏の整理）

- 外部リンクばかりの投稿（毎回リンク＝プロモーション過多判定）
- 同一・類似テキストの短時間反復投稿
- 自動化ツールによる機械的なフォロー・投稿・いいね
- 同一ハッシュタグの乱用
- 短期間の大量フォロー（目安: 1日60人超は危険域）
- 通報の蓄積・規約違反
- 2024年11月の利用規約改定以降、2025年にかけてシャドウバン報告が急増しており、判定が厳格化している。（[s26][s27][s28]）

### 5.3 運用姿勢のNG

- 投稿して放置（初動30分の会話機会を捨てる）
- 負のシグナル対策より先にバズ狙いをする（優先順位は 通報ゼロ → ブロック最小 → ミュート最小 → 「興味なし」最小 → その後にポジティブ最大化）（[s12]）
