# SNS調査の定点観測ソースリスト

各媒体のノウハウ更新時に参照するソースを固定化する。原則: **鮮度が必要な情報（アルゴリズム・新機能・方針）は一次情報＋英語圏**、**国内ソースは日本語圏特有の実践ノウハウ専用**（国内メディアの翻訳・紹介は数週間〜数ヶ月遅れの三次情報が多いため、ニュース用途では使わない）。

## 共通（全媒体）

| 層 | ソース | 鮮度 | 用途 |
|---|---|---|---|
| 一次 | 各プラットフォームの公式ブログ・Newsroom | 即時 | 機能追加・方針の確定情報 |
| 二次（英語） | Social Media Today: https://www.socialmediatoday.com/ | 当日〜数日 | プラットフォーム横断のニュース速報 |
| 二次（英語） | TechCrunch (Social): https://techcrunch.com/category/social/ | 当日〜数日 | 機能追加の速報 |
| 二次（英語） | Hootsuite Blog: https://blog.hootsuite.com/ / Buffer: https://buffer.com/resources/ / Later: https://later.com/blog/ | 数日〜数週間 | アルゴリズム解説の定番。自社データの実測あり |

## 更新運用

- スキル（x-post / instagram-post / threads-post / linkedin-post）の内容を更新するときは、このリストのソースを優先的に当たる。
- リサーチエージェントに調査させる場合は、このファイルをプロンプトに含めて「まずこれらのソースを確認せよ」と指示する。
- 国内メディアの「◯年最新」系SEO記事は、公式・英語圏ソースと突き合わせて日付と整合するものだけ採用する。
