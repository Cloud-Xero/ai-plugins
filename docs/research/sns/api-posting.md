# SNS API 投稿の可否と制限まとめ

作成日: 2026-07-12
YouTube・TikTok の制限は公式ドキュメント等で確認済み。それ以外は知識ベースのため、実装着手時に各公式ドキュメントで最新仕様を確認すること。

## 一覧（自動投稿パイプラインの難易度順）

| 媒体 | API 投稿 | 事前審査 | 主な制約 |
|---|---|---|---|
| Reddit | ○ | 不要 | 技術より文化（サブレディットのルール）が本体 |
| Facebook | ○ | アプリレビュー（軽） | **ページのみ**。個人プロフィールは2018年以降不可 |
| Threads | ○ | 不要（標準的なアプリ登録のみ） | アカウントに直接投稿。ページ・連携不要 |
| LinkedIn | ○ | Marketing Developer Platform 等の申請 | 個人・組織ページとも投稿可 |
| X | ○ | 不要（開発者登録のみ） | 無料枠は投稿 月500件程度。読み取りはほぼ有料 |
| Instagram | ○ | アプリレビュー | プロアカウント化＋Facebookページ連携が必須 |
| YouTube | ○ | **監査を通さないと動画が非公開ロック** | クォータ: デフォルトで実質1日6本 |
| TikTok | ○ | Direct Post は**審査必須（2〜4週間）** | 下書きモードなら審査不要 |

## 媒体別の詳細

### YouTube（YouTube Data API v3 / `videos.insert`）

- **未検証プロジェクトの非公開ロック**: 2020-07-28以降に作成された未監査 API プロジェクト経由でアップロードした動画は**非公開に固定**され、YouTube Studio から手動で公開に切り替えることもできない。「非公開で上げて手動公開」の運用は不可。
- 解除は事後操作ではなく、**API プロジェクトが事前に API Compliance Audit を通っていること**（無料・フォーム申請でアプリの用途を説明）。
- **クォータ**: デフォルト1日10,000ユニット、アップロード1本1,600ユニット → **実質1日6本程度**。引き上げにも監査申請が必要。
- Shorts 専用 API はなく「縦型・短尺の通常アップロード」として扱われる。
- 出典: https://developers.google.com/youtube/v3/revision_history

### TikTok（Content Posting API）

- **Direct Post（直接公開）**: 審査（audit）必須。未審査クライアントは投稿が **SELF_ONLY（本人のみ閲覧）に制限**＋投稿時にアカウントを非公開にする必要＋24時間で5ユーザーまで。
- **下書きモード（MEDIA_UPLOAD）**: **審査不要**。動画がアプリの受信箱に届き、ユーザーがアプリ内で編集・公開を完了する。「下書きアップ→手動公開」ならこちら。
- 審査で渡す情報: アプリ名・用途説明・利用規模の見積もり（アクティブクリエイター数）・統合のデモ・規約準拠確認。期間2〜4週間、複数回のやり取りあり。
- 審査後も 24時間あたりのアクティブクリエイター数・投稿数の上限あり。
- 出典: https://developers.tiktok.com/doc/content-sharing-guidelines / https://developers.tiktok.com/doc/content-posting-api-get-started

### Reddit（公式 API / OAuth `submit`）

- テキスト・リンク・画像投稿が可能。個人スクリプト用途は無料枠（毎分100リクエスト程度）で十分。
- **制約は技術ではなく文化**:
  - アカウントの投稿履歴が自分のリンクばかり → サイト全体のスパムポリシー違反（目安: 自己宣伝は全投稿の1割まで）
  - サブレディットごとに自己宣伝禁止・リンク禁止・カルマ/アカウント年齢の下限などのルールがあり、投稿前の確認が必須
  - 利害関係の非開示（自分の製品を第三者のふりで薦める）は BAN 対象
- リンク自体は問題ない。「参加者として振る舞い、1割で自分のリンク」が健全ライン。

### Facebook（Graph API）

- **Facebookページへの投稿のみ可能**（ページのアクセストークンを使用）。**個人プロフィールへの API 投稿は2018年以降廃止**。
- テキスト・画像・動画・リンク投稿に対応。本番運用には Meta のアプリレビューが必要（ページ投稿系のパーミッション）。

### Instagram（Instagram Graph API / Content Publishing）

- ページを作るのではなく、**Instagram アカウントをプロアカウント（ビジネス/クリエイター）化し Facebook ページと連携**した上で、アカウントに直接投稿する。
- フィード画像・動画・リール・カルーセルの公開が可能。ストーリーズ投稿は制限あり（要最新仕様確認）。
- コンテンツ公開数の上限（24時間あたり）あり。

### Threads（Threads API）

- 独立した公式 API で**自分のアカウントに直接投稿**。ページも Instagram 連携も不要。
- テキスト・画像・動画・カルーセルに対応。

### X（X API v2）

- 開発者登録のみで投稿可能。**無料枠は投稿系のみで月500件程度**（読み取りはほぼ有料プラン必須）。
- 有料プラン（Basic 月$100〜等）で枠拡大。自動投稿はスパム的な連投・同一文反復をやるとシャドウバン要因になる点に注意（→ x-post スキルの NG 事項参照）。

### LinkedIn（LinkedIn API）

- 個人プロフィール・組織ページとも投稿可能。ただし API アクセスには用途に応じたプログラム申請（Community Management / Marketing Developer Platform 等）が必要で、Meta 系より承認の敷居はやや高い。

## 運用上の注意（全媒体共通）

- API 投稿はどの媒体でも「手動投稿と同じコンテンツルール」が適用される。自動化によって NG 事項（各 *-post スキル参照）の検知が緩むことはなく、むしろ機械的なパターンはスパム判定されやすい。
- 投稿ハブを作る場合の推奨順序: Reddit / Facebookページ / Threads → X / LinkedIn / Instagram → YouTube（監査）→ TikTok（審査 or 下書きモード）。
