# pj-成果物の格納スキル（ユーティリティ）

pj-系スキル群が生成した設計ドキュメント一式（`pj_<name>/NN_*.md`）を、
実装プロジェクトのリポジトリ内 `docs/` 配下へ**移設**します。
サービスの実装が始まり、設計ドキュメントをコードと同じリポジトリで管理すべき段階になったら使います。

---

## 実行手順

### 1. 入力の確定（対話ヒアリング）

引数はすべて省略可。**引数の順番に依存せず**、渡された値の形から役割を判定し、
不足している項目だけを対話（AskUserQuestion）で1問ずつ聞き取る。

#### 1-1. 渡された引数の役割判定

順番ではなく**値の形**で判断する。

| 値の形 | 役割 |
|---|---|
| `pj_` で始まる／カレント配下に同名の `pj_*` ディレクトリがある | 移設元（pj_ プロジェクト名） |
| 実在するディレクトリのパス（`/` や `~` を含む、`pj_*` ではない） | 移設先（格納先プロジェクトフォルダ） |
| どちらとも判定できない | 判定せず、対話で確認する（推測で決めない） |

引数が1つだけのときも、この表で役割を判定する。順番の思い込みで
「第1引数＝格納先」と決めつけない。

#### 1-2. 不足項目のヒアリング

以下の順に、**不足している項目だけ**を聞く。すでに引数で確定した項目は聞き直さない。

1. **移設元（pj_ プロジェクト）**
   - カレント配下の `pj_*` ディレクトリを検索する
   - 1つだけ見つかった場合も、それでよいか確認する（破壊的操作のため）
   - 複数見つかった場合は、AskUserQuestion で選択肢として提示する
     （各選択肢の description に、含まれるファイル数と更新日時を添える）
   - 見つからない場合はエラーを伝えて終了
2. **移設先（格納先プロジェクトフォルダのパス）**
   - AskUserQuestion で尋ねる。ユーザーは「その他」で任意のパスを入力できる
   - 選択肢を出せる場合は候補を提示してよいが、**存在するパスだけ**を候補にする
   - 回答されたパスが存在しない場合はエラーを伝えて終了（勝手に作らない。タイポの可能性が高い）
3. **docs 配下のサブディレクトリ名**
   - 既定は `service-design`。AskUserQuestion で「`service-design`（既定）」と
     「`docs/` 直下に置く」等の選択肢を提示し、「その他」で任意名を入力できるようにする

`pj_` プレフィックスが欠けた名前が渡された場合は自動補完する。

### 2. 移設内容の確認

実行前に以下を必ず提示し、ユーザーの確認を取る:

- 移設元: `pj_<name>/` とその中のファイル一覧（`NN_*.md` に一致するもの＋一致しないファイルがあれば別枠で表示）
- 移設先: `<格納先>/docs/<サブディレクトリ>/`（1-2 で確定したもの）
- 移設先に同名ファイルが既に存在する場合は**必ず列挙して警告**し、上書きするか中止するかを確認する（黙って上書きしない）

### 3. 移設の実行

1. `<格納先>/docs/` がなければ作成
2. `<格納先>/docs/<サブディレクトリ>/` を作成
3. `pj_<name>/` 内の全ファイルを移動（`mv`）
   - `NN_*.md` 以外のファイル（画像・メモ等）があった場合も一緒に移動する（成果物の付属物である可能性が高いため）
4. 空になった `pj_<name>/` ディレクトリを削除
5. 格納先が git リポジトリの場合: `git status` で新規ファイルとして認識されていることを確認して報告する（コミットはユーザーの指示があった場合のみ）

### 4. 事後処理

- 移設後のファイル一覧とパスを表示してユーザーに通知
- ドキュメント内に旧パス（`pj_<name>/...`）への相互参照が含まれる場合があるため、
  `grep` で `pj_<name>` への言及を検索し、見つかったら相対参照への修正を提案する
- メモリーや他のドキュメントが旧パスを指している場合は、気づいた範囲で更新を提案する

---

## 重要な注意事項

- ❌ 確認なしに移動・上書き・削除をしない（このスキルの操作は破壊的）
- ⭕ 移設はコピーではなく移動（正本を2箇所に作らない）
- ❌ 格納先パスを推測で補完しない（存在しないパスはエラーにする）
- ❌ 引数の並び順から役割を決めつけない（値の形で判定し、迷ったら聞く）
- ⭕ 移設元に想定外のファイルがあっても捨てない（一緒に移動して報告する）
