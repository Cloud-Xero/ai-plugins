# gsheet-to-md

公開Googleスプレッドシートを全シート漏れなくダウンロードし、シートごとのMarkdownとして保存する。処理の実体は `scripts/download.py`（Python 3 標準ライブラリのみ、venv不要）。

このスキルのベースディレクトリはシステムから `Base directory for this skill:` として提供される。以下 `{skill_base_dir}` はそのパスに読み替えること。

## 設計方針（なぜCSV経由か）

- xlsxエクスポートは日付・数値がシリアル値で格納され、表示値の再現に styles 解析が必要になる。GoogleのCSVエクスポートは**画面表示どおりの値**を返すため、忠実さではCSVが上
- CSVはシート（gid）単位でしか取れないため、取得漏れ対策として `htmlview` のHTMLから**全シートの gid＋シート名を先に列挙**してから1シートずつ取得する
- 生CSVを `csv/` に残すことで、md変換に問題があっても一次データから再変換できる

## 前提と制限

- **公開シート専用**（「リンクを知っている全員が閲覧可」以上）。認証が必要な非公開シートはログインリダイレクトを検知してエラーになる。その場合はユーザーに共有設定の変更を依頼する
- 「共有は可だが閲覧者のダウンロードが禁止」の設定では `export` が 401/403 を返すが、スクリプトが自動で `gviz` エンドポイント（表示値CSV）にフォールバックするため取得できる。疎通確認で `export` が 401 でも `htmlview` が 200 なら本実行に進んでよい
- `htmlview` のHTML構造という非公式な手がかりに依存しているため、Google側の仕様変更で動かなくなる可能性がある。失敗時はエラー内容をそのまま報告する
- セル結合・書式・グラフは保持されない（値のみ）。セル内改行は `<br>`、`|` は `\|` にエスケープされる

## 実行手順

### 1. 引数の確認

`$ARGUMENTS` から以下を読み取る:

- **スプレッドシートURL**（必須）: `https://docs.google.com/spreadsheets/d/...` 形式。URLが無ければユーザーに確認して停止する
- **出力先ディレクトリ**（任意）: 未指定なら AskUserQuestion で確認する。既存ディレクトリを指定された場合は上書きの可能性がある旨を伝える
- URLに `gid=` が含まれていても、**デフォルトは全シート取得**。特定シートだけ欲しいと明言された場合のみ `--gid <GID>` を付ける

### 2. 疎通確認（シート一覧だけ試す）

いきなり全件を走らせず、まず公開状態とシート数を確認する:

```bash
curl -sL -o /dev/null -w "%{http_code}" "https://docs.google.com/spreadsheets/d/<ID>/htmlview"
```

- 200 以外（307→ログイン等）なら非公開の可能性が高いので停止して報告する（`export` ではなく `htmlview` で確認する。`export` はダウンロード禁止設定でも 401 になるが、その場合でもスクリプトは gviz フォールバックで取得できる）

### 3. 本実行

```bash
python3 {skill_base_dir}/scripts/download.py "<スプレッドシートURL>" "<出力先ディレクトリ>" [--gid <GID>]
```

- 実行冒頭でシート一覧（名前と gid）が出力される。シート数が多く時間がかかりそうな場合は `run_in_background: true` で実行し、進捗をユーザーに報告する
- シート間に 0.5 秒のウェイトが入る（レート制限対策）

### 4. 結果の検証

完了後、以下を確認して報告する:

1. 最終行の `完了: シート 成功 N / 失敗 M`
2. **列挙されたシート数と出力mdファイル数（index.md を除く）が一致するか**を確認する。不一致なら取得漏れなので、失敗したシートを特定して報告する
3. 失敗があれば `--gid` 指定で該当シートだけ再実行を試す
4. サンプルとして1シートのmd冒頭をユーザーに提示し、品質（列ズレ・文字化け・改行の扱い）を確認してもらう

## 出力仕様（スクリプトが保証する内容）

**複数シートの場合**（スプレッドシートのタイトルがフォルダ名になる）:

```
<出力先>/
└── <スプシタイトル>/
    ├── index.md          # 取得元URL・取得日時・シート一覧（[[リンク]]）
    ├── <シート名>.md      # シートごとのMarkdownテーブル
    └── csv/
        └── <シート名>.csv # 生CSV（一次データ）
```

**単一シートの場合**（スプレッドシートのタイトルがファイル名になり、index.md は作らない）:

```
<出力先>/
├── <スプシタイトル>.md
└── csv/
    └── <スプシタイトル>.csv
```

- **各シートmdのfrontmatter**（必須）:

  ```yaml
  ---
  source: https://docs.google.com/spreadsheets/d/<ID>/edit#gid=<GID>
  spreadsheet_title: "スプレッドシートのタイトル"
  sheet_name: "シート名"
  gid: "<GID>"
  exported: YYYY-MM-DD HH:MM   # 取得日時(JST)
  ---
  ```

- **index.md**: frontmatter に加え、本文冒頭に `> 取得元: <URL>` と `> 取得日時: <日時> JST`、続けて全シートへの `[[リンク]]` 一覧（取得失敗したシートは失敗と明記）
- **テーブル変換**: 1行目をヘッダー行として扱う。末尾の空行・全行空の末尾列はトリム。セル内改行は `<br>`、`|` は `\|`
- **ファイル名**: OSで使えない文字は `_` に置換。シート名が重複する場合は `_<gid>` を付与

## 追加の整理（ユーザーの要望があれば）

- 「1行目がヘッダーではない」「表ではなく文章として整形したい」シート（規約文など縦長テキストのシート）は、md変換後に生CSV（`csv/`）を元に手で整形し直す。テーブル形式が不自然なシートがあればユーザーに整形方針を確認する
