---
name: harvest-docs
description: カレントプロジェクト内のドキュメント（docs/ 配下などの markdown）から、harvest スキルと同じフォーマットの収穫ノートを生成して HARVEST_OUTPUT_DIR に保存する。「docs から収穫して」「このドキュメントを収穫ノートにして」「docs を harvest 形式にして」と言われたとき、または /harvest-docs [path] で呼び出されたときに使う。セッションからの収穫は harvest スキルの領分で、こちらは既存ドキュメントが対象。出力先未設定の場合は設定を促して停止する。
