# ai-news

主要AI企業の最新ニュースを収集し、日本語解説レポートを生成・保存するスキル。調査と執筆は `ai-news-reporter` エージェントに委譲する。

## 引数

`/ai-news [期間や対象の指定]`

- 引数なし → 直近1日（24時間）、デフォルト4社（Anthropic / OpenAI / Google / xAI）
- 例: `/ai-news 直近1ヶ月` `/ai-news OpenAIだけ` `/ai-news エージェント関連のニュースに絞って`

## 出力先の解決

出力先は環境変数 `AI_NEWS_OUTPUT_DIR` のみを見る（`~/.claude/settings.json` の `env` で設定される）。

- 設定されていればそのディレクトリに保存する
- **未設定なら調査を行わず停止し**、`~/.claude/settings.json` の `env` に `AI_NEWS_OUTPUT_DIR` を設定するようユーザーに促す。設定例:

  ```json
  { "env": { "AI_NEWS_OUTPUT_DIR": "/path/to/news" } }
  ```

  設定後はセッションの再起動が必要な旨も伝える。

## 手順

1. `AI_NEWS_OUTPUT_DIR` を確認する。未設定なら上記の案内をして停止する
2. 引数から対象期間・対象企業・テーマを読み取る（未指定ならデフォルト）
3. `ai-news-reporter` エージェントを起動し、以下を伝える:
   - 対象期間・対象企業・テーマ
   - 出力先: `AI_NEWS_OUTPUT_DIR` の値
   - ファイル名: `YYYY-MM-DD_ai-news.md`（今日の日付。同日に既存ファイルがあれば `YYYY-MM-DD_ai-news-2.md` のように連番を付ける）
   - 対象期間内にニュースがない企業は、その見出しごとレポートに書かないこと
4. エージェント完了後、ユーザーに以下を報告する:
   - 保存先の絶対パス
   - ハイライト（最重要ニュース3件程度）の要約
   - ニュースがなくレポートから省いた企業名（あれば）

## 注意

- 出力先ディレクトリが存在しない場合は、作成してよいかユーザーに確認してから進める
- 期間内の発表が確認できなかった企業は、レポート本文には載せない（セクションごと省く）。ただしユーザーへの口頭報告では隠さず伝える
