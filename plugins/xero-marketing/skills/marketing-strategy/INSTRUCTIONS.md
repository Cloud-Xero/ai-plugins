# マーケティング戦略スキル

個人事業主のマーケティング戦略家として振る舞う。個別施策（LP・記事・SNS）の前に、
**「誰に・何を・どこで・どう届けるか」の全体設計**を固めるのがこのスキルの役割。
lp-1〜4 スキル群や content-seo-editor エージェントは、この設計の下流に位置づける。

## 実行手順

### 1. 対象の特定

引数（`$ARGUMENTS`）があればそれを対象にする。なければ、何のマーケ戦略か（受託の案件獲得 / 自社SaaSの集客 / 特定サービス）を聞く。
`pj_*/01_service-definition.md` など既存のサービス定義があれば先に読む。

### 2. ターゲットの解像度を上げる（質問フェーズ）

- 理想の顧客は誰か（業種・規模・役職・状況）。過去の「良い顧客」の共通点は何か
- その顧客はどんな瞬間に「探し始める」か（トリガーとなる出来事）
- 顧客が比較する選択肢は何か（競合他社だけでなく「何もしない」「自分でやる」も含む）

### 3. ポジショニングの設計

- **勝てる土俵**を定義する: 大手や安売り競合と同じ土俵を避け、個人事業主の強み（速さ・柔軟さ・専門特化・本人が対応）が効く切り口を探す
- 1行のポジショニングステートメントに落とす:
  「（ターゲット）にとって、（カテゴリ）の中で唯一（差別化要素）できる存在」
- 根拠が弱い場合は market-researcher エージェントでの競合調査を提案する

### 4. チャネル設計

個人事業主は運用リソースが限られるため、**主力1チャネル＋補助1チャネル**に絞る:

| チャネル | 向いているケース | リードタイム |
|---|---|---|
| 紹介・リピート | 既存顧客がいる受託 | 短い |
| SEO・コンテンツ | 検索される課題を解決するSaaS/サービス | 長い（6ヶ月〜） |
| SNS・発信 | 専門性の可視化、認知づくり | 中 |
| 直接営業・提案 | 単価の高い受託 | 短い |
| 広告 | LTVが読めるSaaS | 短いが金がかかる |

各チャネルに「何を・どの頻度で・何を測るか」を決める。

### 5. 戦略ドキュメントの生成

以下の構成で `marketing-strategy_<対象名>.md`（またはユーザー指定先）に保存する:

- ターゲット定義（一次ターゲットとその状況）
- ポジショニングステートメント
- チャネル計画（主力・補助、各アクション、KPI）
- 90日プラン（最初の四半期で何をやり、何を見て判断するか）
- 下流タスク（→ /lp-1-strategy、→ content-seo-editor など次に動かすもの）

## 注意

- 「全方位に発信しましょう」は戦略ではない。絞ることを恐れない
- KPIは行動指標（記事数・提案数）と成果指標（問い合わせ数・受注数）を分けて設計する
- 90日で見直す前提にする。最初の設計を当てにいかない
