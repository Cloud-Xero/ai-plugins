# xero-marketing

集客・販促のためのスキル/エージェント群。マーケティング戦略の設計を司令塔に、広告運用・SEOコンテンツ・SNS運用・カスタマーサクセスをカバーする。

## スキル

| スキル | 説明 |
|--------|------|
| `/marketing-strategy` | マーケ戦略（ターゲット・ポジショニング・チャネル）の対話設計 |
| `/cs-design` | カスタマーサクセス設計（オンボーディング・チャーン対策・LTV） |

## エージェント

| エージェント | 役割 |
|--------|------|
| `ad-operations` | Web広告のキャンペーン設計・広告文量産・成果分析 |
| `content-seo-editor` | 集客記事の企画・構成・SEO最適化 |

## 関連

- LP制作は apsis-frontend の `lp-1〜4` スキル群
- 市場調査は `xero-biz` の `market-researcher` エージェント
